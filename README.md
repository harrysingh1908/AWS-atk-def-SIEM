# AWS-atk-def-SIEM

SIEM Lab Infrastructure
Overview

This project sets up a cloud-based Security Information and Event Management (SIEM) lab on AWS using Terraform. It includes an attacker machine and two victim machines for simulating and detecting security threats.

Getting Started

Prerequisites:

An AWS account with free-tier access.

Terraform installed on your local machine.

Configuration:

Update the terraform.tfvars file with your key pair name.

Deploying the Infra:

Run terraform init to initialize the configuration.

Run terraform apply to create the infrastructure.
